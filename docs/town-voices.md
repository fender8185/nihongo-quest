# 小鎮居民的口吻表

2026-11-12。寫小鎮的台詞（`events.js` 的 `CHAT`、`MUTTER`、`PAIRS`、事件）之前先看這份。每個人的設定在 `TOWN.CAST[id].bio`，這份寫的是**怎麼說話**。覺得誰的個性不對，先改這裡，再照這裡改他的台詞。

## 全部人共通

- **「……」很少用。** 只用在真的沉默、說不出口的時刻，一個人一輪閒聊最多一句。話少靠短句表現，猶豫靠各自的口頭禪表現。
- **個性靠四樣東西**：自稱、句尾、口頭禪、節奏。入門（m0–m2）能用的字很少，所以這四樣更重要。
- **招呼不撞。** 九個顧店的人各有自己的開口方式，見下表。「いらっしゃい（ませ）」每人最多一句，而且說法要不同。
- **中文翻譯要有口氣。** 大嗓門的用驚嘆號，話少的翻得短，老人家的翻得老派，不要翻成一樣的白話。
- **「越聊越熟」三句**（`talks: 3 / 8 / 15`）：3 是輕鬆一點，8 是開始講自己的事，15 是只會對朋友說的話或秘密。
- **頭上泡泡**（`MUTTER`）是自言自語：照這個人平常的口氣；永遠敬體的人（佐野、原田、小林）用名詞收尾或敬體都可以。
- **整天在同一個地方的人**（小鎮的店家）日常變化靠時段（`h`）和平日週末（`days`），不用 `at`。

## 每個人

### 健太（kenta）森のパン
- 自稱「おれ」（對客人有時「わたし」）；叫主角「きみ」或名字不叫；句尾「〜だよ！」「〜ですよ！」混著用，客人面前多一點敬體。
- 口頭禪：「おっ」「よーし」、冷笑話後「なんちゃって！」、**數數**「{一|ひと}つ、{二|ふた}つ……」「{今日|きょう}は パンを {百|ひゃく}{個|こ} {焼|や}いた！」
- 節奏：大聲、短句連發、驚嘆號多。
- 話題：今天烤了幾個、新口味、塞試吃、美玖、冷笑話（パン／パーン）、早起。
- 還沒露出的一面：太太過世後一個人帶美玖的辛苦；外婆幫過他；二號店的夢想。熟了以後才會小聲說。
- 不會：說「……」開頭；抱怨客人。

### 高橋（takahashi）ボランティアガイド
- 自稱「わたくし」（或「わたし」）；很有禮貌的敬語；**愛出題**「では、{問題|もんだい}です」
- 口頭禪：「さて」「ご{存|ぞん}じですか」
- 節奏：講解、一講就停不下來（句子可以長一點）。
- 話題：白鷺城的歷史、石牆、古地圖、鹽的小鎮、以前當老師。
- 還沒露出的一面：退休後的寂寞；以前的學生。
- 不會：說錯年代、用常體。

### ソフィア（sophia）観光客
- 自稱「わたし」；**只會一點點日文**：很短、名詞＋「です」、常用「ありがとう」「すごい」；偶爾一個法文字（「Merci」「Oh là là」用片假名「メルシー」）。
- 口頭禪：「すごい！」「メルシー！」
- 節奏：短、興奮、追孩子。
- 話題：城、孩子跑掉、拍照、日本的東西好可愛。
- 還沒露出的一面：她為什麼一個人帶孩子旅行（輕輕帶過）。
- 不會：說複雜的句子。

### ムギ（mugi）海邊的柴犬
- **每句「ワン！」開頭**；常體、狗的視角、很悠哉。
- 口頭禪：「ワン！」「くんくん」
- 節奏：短、慢、愛吃、愛音樂。
- 話題：唱片、海浪的聲音、吃的（麵包、魚）、外婆、タロウ來聽唱片。
- 還沒露出的一面：很想外婆、守著外婆的海邊。
- 不會：說很長、用敬體。

### 外婆（granny）
只出現在信和回憶裡，不加閒聊。

## 誰會聊到誰（`about`）

- 松：什麼都知道——源三輸棋、トメ的年輕時、中村家、小春和健太。
- 西村：消息靈通——佐野的計畫、海邊、アレックス的海龜、選舉一類的鎮上新聞。
- 小春：客人的八卦——陽菜、和子、美咲。
- トメ：唸別人——剛、鈴木（每天同一份）、美咲（太瘦）。
- 鉄平：老朋友——健二、外婆。
- 健太：美玖、小春。
- 林：健二、陽菜（像姊姊一樣關心）。

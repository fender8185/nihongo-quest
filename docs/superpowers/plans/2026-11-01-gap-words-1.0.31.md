# N5／N4 補字（1.0.31） — 實作計畫

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 把課程大綱缺口檔（`curriculum/gaps-n5n4.json`）裡 98 個字做成內建單字，包括例句和中文。N5 有 38 個，N4 有 60 個，DATA_VERSION 升到 17。設定頁標出等級清單的來源（Waller，CC BY）。

**Architecture:** 照 1.0.8 新字的做法：
- 寫一份指南。兩個內容小隊照指南寫候選字，`scripts/check-vocab.py` 在無頭瀏覽器裡驗，要 0 BAD。
- 合併腳本編 id，寫進 `data.js`。
- 新工具 `scripts/furi-snapshot.py` 在合併前後各存一份「所有內建文字的振假名」，比對出被新字改到的句子。N3 每一批也會用到這個工具。
- `check-vocab.py` 多一個警告：N5 例句用到只在 N4 教的字。
- 程式只改設定頁的一行出處、版本號和版本紀錄。

**Tech Stack:** 單檔 `index.html`（原生 JS），`data.js`（第 3 行是 `const DATA = {...};`）；Python 3 工具和 e2e 測試共用 `tests/e2e/cdp.py`（無頭 Chrome）。

**Spec:** `docs/superpowers/specs/2026-10-31-n3-level-design.md` §11 的 1.0.31 列、§5.5（同寫法的 16 個字不在這一版）；`docs/superpowers/specs/2026-10-31-curriculum-n3-n1-design.md` §3（N5／N4 缺口）。

## Global Constraints

- 分支 `feat/1.0.31-gap-words`。版本號有三處要一致：`APP_VERSION = '1.0.31'`、`CACHE = 'nq-v1.0.31'`、data.js 的 `DATA_VERSION 17` 和 index.html、sw.js 裡的 `data.js?v=17`；`bash scripts/test.sh` 會檢查。
- 收的字：缺口檔 N5、N4 的 `words` 和 `added` 全部，扣掉跟 app 或彼此同寫法的 16 個：
  - N5：一日 いちにち、九 く、四 し、七 しち、十 じゅう、何 なん、一月 ひとつき、毎月 まいげつ、毎年 まいねん、行く ゆく、私 わたくし、日本 にっぽん、日本 にほん
  - N4：明日 あす、君 くん、開く ひらく
  - 剩下 N5 38 個、N4 60 個。
- 每個字的 `w r m c lv` 照缺口檔原樣。小隊補：
  - `p`：其中之一 `n v5 v1 vs vk i na adv conj pron q cnt exp`
  - `ex exZh ex2 exZh2`：兩句例句，各有一個 `{標記}`，以「。」結尾；檢查器要能幫每個漢字標振假名。
  - N5 的例句只用 N5 以下的字和文法；N4 的例句只用到 N4。
- id 照缺口檔的順序：N5 `n5g-001`〜`n5g-038`，N4 `n4g-001`〜`n4g-060`。
- 設定 › 外觀，「版本 …」下面加一行，文字固定：「單字、漢字、文法點的 JLPT 等級參考 Jonathan Waller 的 JLPT Resources（tanos.co.uk，CC BY）。」
- 振假名比對：合併前後，既有內建文字的振假名一句都不能被改掉；有變化就修到沒有，修不了的在 commit 訊息寫明原因。
- 音檔不在程式裡：發佈後由管理者在 設定 › 雲端音檔 按「生成」，補上新字和例句的音檔。
- 上線（使用者 2026-11-01：「1 做完先推一版」）：全套測試通過後，推分支，用 `scripts/pages-branch.sh feat/1.0.31-gap-words` 讓 Pages 指過去給使用者試。使用者確認後合回 main、推 main，再用 `scripts/pages-branch.sh main` 把 Pages 指回 main。
- commit 結尾兩行：`Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`、`Claude-Session: https://claude.ai/code/session_0152ktZTKfem2xo6E9jkfigM`。

## Review Focus

1. **新的漢字字加進讀音索引，改掉既有句子的振假名。** 例如最長比對把舊句子切成新字。→ Task 1 的快照，加上 Task 3 Step 5 的比對。
2. **新字跟既有的字同讀音**（ほう／方 這類）：「中翻日」的選項出現兩個都對的答案。→ Task 3 的測試：每個新字的 `recallOptions` 不能有同讀音的字。
3. **新字的意思跟既有的字重疊**（よい「好（較正式、書面）」／いい「好」）：「看字選意思」出現兩個都對的意思。→ Task 3 的測試：每個新字的 `meaningOptions` 不能有跟它重疊的意思。
4. **N5 例句用到 N4 才教的字**，N5 學習者看不懂。→ Task 2 的檢查器警告，小隊要清到 0。
5. **漏掉同寫法的字。** 這 16 個字現在進來，題目和讀音會亂。→ Task 3 的測試：新字的寫法跟所有內建字都不同。

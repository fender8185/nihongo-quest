# 出題規則減法（1.0.21） — 實作計畫

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 保留分層，只砍它周圍的規則：
- 記憶率固定 90%
- 錯題本不再每天另外抽（錯題不算在 50 題內）
- 四顆答對不強制升五顆
- 入門測驗跟其他階段一樣
- 通過測驗不動聽力閱讀，標記不分散到期日
- 拿掉過渡規則

另外把單字的「已熟練」改成五顆＋假名拼字答對過。

**Architecture:** 全部是 `index.html` 現有函式裡的減法，不加新欄位。
- 排程：
  - `fsrsInterval` 用固定記憶率。
  - `srsAnswer` 拿掉升五顆；移出改看答題前是否已熟練。
  - `computeDailyPlan` 把錯題另外全列，拿掉錯題本 queue。
- 測驗與標記：`finishStageTest` 對所有階段呼叫 `markPassedStage`，`bulkApply` 只剩四顆一種。
- 標籤：`srsLevelLabel` 照題目種類判斷，新函式 `canSpell`、`spelled`；`makeVocabQuestion` 對四顆以上沒拼過的字強制出 `v-spell`。

**Tech Stack:** 單檔 `index.html`（原生 JS）；e2e `tests/e2e/*.py`（headless Chrome、`cdp.py`）；模擬程式 `scripts/sim-schedule.js`（Node）。

**Spec:** `docs/superpowers/specs/2026-10-30-rule-cuts-design.md`

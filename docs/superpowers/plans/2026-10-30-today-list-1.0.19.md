# 今天的清單、今日數字與模擬考獨立（1.0.19） — 實作計畫

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 今天的題目在當天第一次需要時排好、存進 `state.today.plan`，圓圈改成清單做完的百分比，「今天做了」與側欄改算今天作答過的不重複題目，模擬考不再碰排程、錯題本、正確率和題數。

**Architecture:** 原本的 `dailyPlan()` 改名 `computeDailyPlan()`，新的 `dailyPlan()` 只在當天第一次（或起點、學習階段改變時）呼叫它，把各清單的 key 存起來，之後都從 key 還原、濾掉 `state.today.ans` 裡已作答的題目，回傳跟原本一樣形狀的物件，所以呼叫端不用改。`srsAnswer()` 和手動錯題的作答呼叫 `noteAnswered(key)`。模擬考和階段測驗只寫 `dailyLogs[今天].ex`。

**Tech Stack:** 單檔 `index.html`、`sync-core.js`（Node 測試 `tests/sync-core.test.js`），e2e 用 `tests/e2e/cdp.py` 的 headless Chrome。

**Spec:** `docs/superpowers/specs/2026-10-30-today-list-design.md`

## Global Constraints

- 分支 `feat/today-queues`，從 main 的 e52f1fb（1.0.18 離線語音）之後開出，1.0.20 也接在同一個分支。最後一個 task 才把 `APP_VERSION` 改成 `'1.0.19'`、`sw.js` 的 `CACHE` 改成 `'nq-v1.0.19'`。data.js 不動。
- `state.today.plan` 的清單名稱固定為 `PLAN_LISTS = ['dueV','dueG','dueC','dueK','dueL','dueR','dueA','newV','newG','newC','newK','newL','newR','newA']`，另有 `kept`。
- 手動錯題作答時的 key 是 `'m:' + 錯題 id`。
- 圓圈中間只寫百分比（`57%`），不寫題數。按鈕文字照 spec：「開始練習・這組 N 題」，下一行「今天還有 M 題」（只在 M > N 時顯示）。尾巴併組條件：取完一組後剩下 ≤ 5 題，或少於一組的四分之一。
- 學習紀錄文字：有 `items` 的日子 chip 寫「N 題」，說明寫「N 題・作答 M 次（…）」；舊日子寫「作答 M 次」；有 `ex` 的日子說明最後加「・模擬考與測驗 K 題」。
- 每個 task 先寫測試、看它失敗，再實作。這台電腦的 `python3 -I` 載不到 websockets，所以 e2e 用 `python3 tests/e2e/<檔名>.py` 跑，不加 `-I`；`scripts/test.sh` 只用它的 node 檢查部分（`node --check …` 和 `node tests/sync-core.test.js`）。cdp.py 偶爾出現 `tabs` 錯誤是已知的測試環境問題，重跑即可。
- commit 結尾照舊加兩行（Co-Authored-By、Claude-Session）。

## Review Focus

1. 練到一半才打開 app（例如先用字卡學了幾個字）：清單排出來時不會包含今天已經答過的題目，但「今天做了」要算進字卡那幾題。→ Task 2 `test_items_answered_before_the_plan_count_but_stay_out_of_it`。
2. 兩台裝置同一天練習後同步：作答過的題目要合併，不能因為採用另一台的版本而變少。→ Task 1 的 Node 測試 `mergeStates unions same-day answered keys`。
3. 清單裡的題目後來被隱藏或刪除（自訂字卡）：不能報錯，總數要扣掉。→ Task 2 `test_missing_keys_are_skipped`。
4. 「手滑，不算」之後，那一題不能還算在「今天做了」裡。→ Task 1 `test_slip_takes_the_answer_back_out`。
5. 入門自動結束或入門四題選完、正式進入正課：清單重排，已經做完的題目不能消失。→ Task 2 `test_stage_switch_rebuilds_the_plan_and_keeps_answered_items`。

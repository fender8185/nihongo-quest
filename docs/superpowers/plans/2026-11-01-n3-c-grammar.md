# N3 ③ 文法和講解（1.0.33 的第三段） — 實作計畫

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 把課程大綱 `curriculum/n3.json` 的 15 個單元（m19–m33）、133 個文法點做成內建資料：第四、第五階段、單元、講解、約 800 題文法題。1.0.33 一起推，這一段不推。

**Architecture:**
- 先改工具：`check-grammar.py` 認得 N3。
  - `--with FILE`：先把一份單元檔（`units`、`lessons`、`phases`）放進 app 再檢查，題目就能指向還沒合併的單元。
  - `lv` 照單元的 `lv`。
  - 新單元的 `pt` 對大綱的文法點。
  - 四種題型（choice、meaning、order、conj）都檢查。
- 一個小隊一個單元，寫這個單元的講解和題目，每次並行 5 個，每隊檢查到 0 problems。
- 全部回來後一次合併：
  - 題目 id `m19-01…`，接在 m18 後面。
  - `UNITS`、`LESSONS`、`PHASES` 照大綱。

**Tech Stack:** data.js（第 3 行 JSON）；`scripts/check-grammar.py`（無頭 Chrome）；Python 合併腳本（scratchpad）；e2e `tests/e2e/test_content.py`、`tests/e2e/test_levels_n3.py`。

**Spec:** `docs/superpowers/specs/2026-10-31-n3-level-design.md` §4.4、§5.1、§5.3、§5.4、§10、§11 的 1.0.33 ③；課程大綱 `curriculum/n3.json`（`phases`、`units[].points`）。

## Global Constraints

- 單元照大綱：
  - id、`short`、`title` 照 n3.json。
  - `ph`：m19–m26 是 4，m27–m33 是 5。
  - `lv: 'N3'`。
  - `weeks` 接在 m18（第 35–36 週）後面，照文法點數分 24 週（N3 約 169 天）。
  - `desc` 一句話。
- 階段：
  - `{id: 4, title: '第四階段：N3 文法', span: '第 10–12 個月'}`
  - `{id: 5, title: '第五階段：N3 進階與總複習', span: '第 13–15 個月'}`
  - 標題照 n3.json 的 `phases`。
- 講解跟 m18 同格式：`formula`、`overview`、`sections[{h, rule, points[], ex[{jp, zh}]}]`。每個文法點落在一個 section，每個 section 至少 2 句例句。
- 題目欄位跟現有的一樣（`id u t lv d pt sec …`）：
  - `pt` 是大綱文法點的 `p`。
  - `sec` 是那個點所在的 section。
  - `lv: 'N3'`。
- 每個文法點至少 3 題 choice。每個單元：
  - meaning 至少 5 題，order 至少 5 題。
  - conj 只給跟動詞變化有關的點（例：〜させられる）。
  - 全部約 45–60 題。
- 例句和題目用 N5–N3 的字，每個漢字都要有讀音（N3 的題目「kanji without furigana」算 problem，不是 warning）。
- 不抄教材、考古題；全部自己寫。

## Review Focus

1. **文法點對錯單元或 section，講解和題目對不起來。** → 合併腳本逐點比對大綱；資料測試查每個點的題數。
2. **N3 文法題的選項有兩個以上都對（尤其意思相近的點：〜によって／〜によると、〜ばかりか／〜ばかりでなく）。** → 指南要求干擾選項在文法上錯，抽查。
3. **新單元進來後，課程頁、階段測驗、每日新題出錯（第五階段結束後的下一個單元、N3 封死）。** → `nextUnitAfterStage`、階段測驗的組題測試。
4. **假 N3 測試（test_levels_n3.py）跟真的 N3 資料撞號（m19、n3a-001、PHASES id 4）。** → 假資料先把真的 N3 拿掉再放假的。
5. **每天的量：N3 文法加進來後，課程中段每天的新題、複習量過多。** → `sim-schedule.js --levels` 跑 N3 大小的題庫，記下數字。

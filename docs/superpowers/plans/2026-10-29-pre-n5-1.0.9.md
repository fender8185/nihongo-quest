# PRE_N5 第三版（1.0.9）：單字頁改版（等級 → 主題 → 漢字） — 實作計畫

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 單字頁第一層變成三個等級（入門／N5／N4），每個等級頁有進度環、本級主題卡（卡上列會碰到的漢字）、本級漢字依主題分組；入門頁多一張依熟練度上色的五十音表。字卡、單字表、匯入保留；舊的「主題」「漢字」分頁併入等級頁。

**Architecture:** 新增 `renderVocabLevel(view, lv)`（route `#/vocab/level?lv=…`），資料全部由現有的 `REG`/`state.srs` 現算：`levelStats(lv)`、`themeStats(lv)`、`kanjiThemeOf(k)`（漢字 → 含它的內建字最多的主題）。練習入口沿用 `startSession`：單字加 filter `t:<lv>:<theme>`、漢字加 `{ lv }`、假名加 `{ row }`。舊 route `#/vocab/themes`／`#/vocab/kanji` 導到對應等級頁。

**Tech Stack:** 同前；`ringHtml(ratio, inner, size)`（3985）與 `segBarHtml` 已有。

**Spec:** `docs/superpowers/specs/2026-10-29-pre-n5-level-design.md` §6、§7、§9 第 3 版。

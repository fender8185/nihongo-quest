# 小鎮居民活起來 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 居民在自己的點附近走走停停、冒泡泡、兩人對話、換時段走出走進；閒聊照條件挑；事件「……」降到一成。

**Architecture:** 兩個新檔：`js/71i_chat.js`（`CHATPICK`，純函式，node 可以直接測）和 `js/71j_life.js`（`TOWNLIFE`，管一個 `.yard` 裡居民的位置、動作、泡泡）。`TOWNEV`（`js/71c_town.js`）的 `castHtml`／`talk`／`chatLine` 接上它們；`renderOutside`（`js/71a_yard.js`）畫好場景後叫 `TOWNLIFE.start`；`sceneMinute`（`js/70_app.js`）重畫前先叫 `TOWNLIFE.change`。台詞資料全在 `events.js`。

**Tech Stack:** 原生 JS（全域腳本，沒有打包）、CSS、node:test、headless Chrome e2e（`tests/e2e/cdp.py`）。

**Spec:** `docs/superpowers/specs/2026-11-12-town-life-design.md`

## Global Constraints

- 只上 test 分支；三步各自 commit，最後一次推上 test。sw.js `CACHE = 'nq-v1.13.0-test.1'`；`APP_VERSION` 不動（test.sh 只比數字部分）。
- `events.js` 一改就把 `EVENTS_VERSION` 42 → 43，`index.html` 的 `events.js?v=43`、sw.js PRECACHE 一起改（test.sh 會擋）。整輪只加一次。
- 新的 js 檔要加進 `index.html`（`71h_stages.js` 之後，`71i_chat.js` 再 `71j_life.js`）和 sw.js PRECACHE。
- 日文：漢字一律 `{漢字|かな}`；超出單元程度或課程沒有的字 `{漢字|かな|中文}`；人名在 `TOWN.NAMES` 不用註。
- 時段：`am` 5–11、`noon` 11–15、`pm` 15–19、`night` 19–5（含頭不含尾）。`fresh` = 事件完成當天起 3 天內（差 0–3 天）。
- 範圍預設 `roam [70, 18]`；停 4–10 秒、走 1–3 秒；走近 120px；泡泡每 8–15 秒、顯示 2.5 秒；兩人相距 > 160px 先走過去；兩人對話機率 1/3、每句間隔 2 秒；最近 5 句不重複；離場最多 4 秒。
- 「……」上限：居民事件台詞 12%、CHAT 10%。
- 減少動態（`prefers-reduced-motion: reduce`）：不走、不做小動作、不走出走進；泡泡照舊。
- 程式風格照周圍：短註解說「為什麼」、一行一個想法、`const` 箭頭函式、IIFE 模組。
- 迭代時跑相關的單一 e2e 檔（`.venv/bin/python3 -I tests/e2e/<file>.py`）；最後跑一次完整 `scripts/test.sh`。

## Review Focus

1. 場景在居民走到一半時被重畫（同步、換時段、離開這個地方）→ 舊的 `requestAnimationFrame`、計時器不能對已移掉的節點報錯，也不能殘留在新場景。（Task 1 測）
2. 點一個正在走的人 → 主角要走到他**現在**的位置，不是原本的點；點了之後又點別處（沒開成對話）→ 他不能永遠僵住。（Task 1 測）
3. 居民走進長椅、攤位、建築（`WALK_BLOCK`）或走出可走的範圍。（Task 1 測）
4. 對話框開著時時間到了 → 不做離場，關掉後下一分鐘再做；對話中不冒泡泡。（Task 2 測）
5. `localStorage` 讀寫會丟例外（私密模式）→ 閒聊照樣能開。（Task 3 測）

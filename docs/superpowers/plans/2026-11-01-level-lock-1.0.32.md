# 每一級封死（1.0.32） — 實作計畫

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 新題一次只出一級。目前這一級的單字、漢字、文法都學過一次，下一級才開始。複習一律看紀錄，不看等級或單元。

**Architecture:**
- 在 index.html 的等級區塊（`LV_RANK` 附近）加一組等級函式：`COURSE_LEVELS`、`courseLevel`、`unitLevel`、`unitDone`、`levelLeft`、`curLevel`、`grammarPause`。
- 以下各處改成問這組函式：新單字、新漢字、新文法、`splitNew` 的比例、主題線、字卡的混合牌組、課程進度、今日頁和課程頁的說明。
- 複習範圍（`computeDailyPlan` 的 `scope`、`vocabStats` 的待複習數）改成看紀錄。
- 程式其他地方的一般化（單字頁分頁、學習分析、讀音優先序……）在 1.0.33 做；這一版的 `COURSE_LEVELS` 只有 N5、N4。

**Tech Stack:** 單檔 `index.html`（原生 JS、全域函式）；e2e 用 `tests/e2e/*.py`（無頭 Chrome，`cdp.py`）；模擬程式 `scripts/sim-schedule.js`（node）。

**Spec:** `docs/superpowers/specs/2026-10-31-n3-level-design.md`：§4.2（封死）、§4.3（比例）、§4.6（複習看紀錄）、§6（頁面）、§10（測試，排程那一版）。

## Global Constraints

- 分支 `feat/1.0.32-level-lock`。`APP_VERSION = '1.0.32'`、`CACHE = 'nq-v1.0.32'`；資料不變，DATA_VERSION 維持 17。
- 正課裡入門和 N5 算同一級：`courseLevel('PRE_N5') === 'N5'`。入門階段（`inPreStage()`）的規則不動。
- 目前這一級 `curLevel()`：`COURSE_LEVELS` 裡第一個還有東西沒學完的等級：
  - 有沒看過的內建單字或漢字，
  - 或有沒完成的單元。單元完成 = 在 `completedUnits` 裡，或單元裡的題目都看過。
  - 全部學完時是最後一級。
- 新題只出目前這一級：
  - 單字、漢字照等級。
  - 文法照單元：第 0 週不算，只出目前這一級的單元，不進下一級。
  - 這一級的文法學完、單字或漢字還沒學完時，新文法停下來，名額照 `splitNew` 原本的補位規則給單字和漢字。
  - `splitNew` 的比例只看目前這一級剩下多少（單字、這一級沒完成的單元裡的文法題、漢字）。
- 複習看紀錄：
  - 內建的單字、文法、漢字、變化練習，只要有紀錄就照排程進每日複習。
  - 匯入字卡照「匯入字卡」的設定。
  - 聽力、閱讀不變。
- 手動的路照舊：
  - 單字頁的等級分頁、主題、字卡的等級牌組（N4 牌組直接出 N4 新字），
  - 課程頁的單元和「從這個單元開始」，
  - 階段測驗。
  - 混合牌組（全部）的新字跟每日一樣，只出目前這一級。
- 新文法因為封死停下來時，今日頁的 `plan.note` 和課程頁最上面寫同一句：
  - 文字固定：`新文法先停：{等級} 單字還剩 {v} 個、漢字還剩 {k} 個，學完就進第 {n} 單元。`
  - 單字或漢字剩 0 就省略那一段。
  - `{n}` 是下一級第一個單元的編號（m7 → 7）。
- 單字頁頁首原本的「N4：N5 單字都學過一次後開始（還剩 N 個）」改成：`N4：N5 的單字、漢字、文法都學過一次後開始`，後面括號列出還剩的數字（例：「還剩單字 38、漢字 2」）。
- 課程進度（`coursePace`）：一級接一級。每一級學完的天數 = 前一級學完的天數 + 這一級剩下的題數 ÷ 每天的新題數；原本的 ΣU·N/U 拿掉。
- 刪掉沒人用的 `inDailyReach`（延後的小問題 M6）。
- commit 結尾兩行同前一版。

## Review Focus

1. **「這一級學完」永遠不發生**：例如課程頁把單元標成完成，但單元裡有題目從沒出過；或某一級有出不來的題目。→ Task 1 測試：`applyStartUnit` 標完成的單元不擋；隱藏的題目不算。
2. **已經在 N4 單元的人（`currentUnit` 是 m9），N5 單字還沒學完**：新文法要停，N4 單元的題目一題都不能出，也不能被 `autoAdvanceUnit` 往前推。→ Task 1 測試。
3. **提前學的題目**：N4 的字、後面單元的文法、N4 漢字，隔天起照排程複習，不能消失。單元往回調後，後面單元照常複習。→ Task 2 測試。
4. **一級學完的那一天**：下一級的單字、文法、漢字都要接上，不能有一天是零新題。→ Task 1 測試，加上 Task 4 的模擬程式。
5. **字卡和單字頁的手動路**：N4 牌組要出 N4 新字；混合牌組不能出 N4 新字（還在 N5 時）。→ Task 2 測試。

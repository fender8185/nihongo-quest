# 活用題輸入模式 ＋ 生成式變化練習 設計規格

日期：2026-10-28　狀態：使用者口頭核准（「ok」）

## 1. 問題
活用題（動詞 `t:'conj'` 168 題、形容詞 `t:'adj'` 22 題）全是四選一；錯誤選項由 JConj 生成，常能靠排除法選到（只有一個選項以「って」結尾）。FSRS 記到的是「答對」，練到的只是辨認，不是產出。40 種形態分布很不平均（て形 41、意向 16、受身て形 8……）。

## 2. 目標
1. 熟練度 1 以上的活用題改成「自己拼／打出答案」，不再給選項。
2. 答錯的「再練一次」複本與新題的「換個方式再考」在活用題上都走輸入模式。
3. 新增「變化練習」：以形態為單位排程，動詞每次從已學過的單字隨機抽，句子背不起來。
4. 學習分析能分開看選擇與輸入的正確率。

## 3. 規則
### 3.1 作答方式（設定 `conjInput`，預設 `auto`）
- `auto`：該題沒有 SRS 紀錄或 `b === 0` → 四選一（現況）；`b >= 1` → 磁貼。
- `choice`：一律四選一。`tiles`：一律磁貼。`type`：一律鍵盤輸入（iPhone 要先加日文鍵盤，設定頁說明）。
- 「畫線的動詞是哪一種形」（`g-identify`）變體的條件不變（`b >= 2`、30%），優先於上述判斷。
- 格式名：動詞 `g-conj-type`、形容詞 `g-adj-type`（磁貼與鍵盤同一格式名，`q.inputMode` 記 `tiles`／`type`）。

### 3.2 磁貼
- 磁貼 = 答案的「符號」：漢字連續段（含其後的 `[讀音]`，例如 `来[こ]`、`勉強`）是一塊，其餘每個假名一塊；再混入錯誤變化（`verbDistractors`／`adjDistractors`）裡、答案沒有的假名 3 至 4 塊；全部打亂。
- 漢字塊顯示時走 `furi()`（有括號讀音就顯示振假名，不顯示方括號）。
- 點到的塊數等於答案塊數時判答；「退一格」可收回；「看答案」算答錯（沿用 `custom-giveup`）。

### 3.3 鍵盤輸入
- `<input class="input jp conj-in" lang="ja">` ＋「確定」；Enter 送出；空白不送。
- 正規化 `kanaKey(s)`：去掉半形／全形空白、片假名轉平假名、`JConj.normJa`（括號讀音取代前面的漢字）。
- 判對 `conjMatch(typed, ans)`：`kanaKey(typed)` 等於 `kanaKey(ans)` 或等於 `kanaKey(answerKana(ans))`；`answerKana(ans)` 用 `furi()` 把答案全部轉成假名（漢字查不到讀音時維持漢字）。所以「行って」「いって」都對；形態錯就是錯，沒有部分分數。

### 3.4 回饋
- 答錯時除了既有的「正確答案是…」，多一行「你的答案：」，第一個分歧的字標紅（`firstDiff`）。磁貼與鍵盤都顯示。

### 3.5 與排程的關係
- 輸入題照常 `srsAnswer`；另以 `recordFormat(rec, fmt, ok, 'gf')` 記格式（現在只對 choice 題記）。
- `grammarHasFormats` 對 conj／adj 題：設定不是 `choice` 時回傳 true → 新題答對後的「換個方式再考」出輸入版（`avoidFmts` 含 `g-conj` 時給輸入版；含輸入版時 `auto` 給四選一，其餘回 null）。
- 答錯後的「再練一次」：原題是輸入版就仍用輸入版（`forceFmt`），不退回四選一。

### 3.6 變化練習（kind `c`）
- 形態家族：`FORM_LABEL` 的鍵裡、題庫 conj 題有用到的（扣掉 `dict`）：te、ta、nai、masu、ba、pot、vol、pass、caus（`causpass` 無標籤，不開）。每個家族一個項目 `key = 'c:<fam>'`，`u` = 題庫中該家族最早出現的單元，`forms` = 題庫中該家族用到的具體形態（例如 pass → passte、passmashita、passmasu、passnai）。
- 項目掛在 `REG.drills`，也放進 `REG.byKey`（錯題本能連回）。
- 出題：隨機抽 `forms` 之一與一個動詞。動詞來自 `REG.vocab` 中 `p ∈ {v5, v1, vs, vk}` 且 `state.srs[key].b >= 1` 的字（群組對應 v5→'5'、v1→'1'、vs→'s'、vk→'k'）；不足 5 個時用全部動詞。題幹：動詞（振假名）→ 形態名稱，並以「食べる」示範該具體形態（例：受身形，像「食べられました」）。作答一律輸入（設定 `choice` 時用磁貼）。
- 排程：和其他軌一樣只有「到期」與「新」。每天最多 `conjDrillPerDay`（預設 3）題；到期的家族先（最逾期優先），再未開始的家族（照單元順序）；只出 `u` 在目前單元以前的家族。計入負荷上限但不被削減。`state.today.newC` 計數。
- 統計歸類為文法（`recordAction` 的 type 與 kind 都給 `'g'`）；`RELEARN_KINDS` 加 `c`，答錯走 1／3／7 階梯；錯題本以「書く → て形」為題幹、答案為正解，錯題練習時重新抽動詞（不是同一題）。
- 加練、單元練習不含變化練習（YAGNI）。

## 4. 設定頁文案
- 「活用題作答方式」：自動（熟了之後改成拼出來）／一律選擇／一律假名磁貼／鍵盤輸入（iPhone 請先在「設定 › 一般 › 鍵盤」加入日文鍵盤）。
- 「每天變化練習」0–10 題：「以形態為單位排程，動詞從你學過的單字裡隨機抽。」

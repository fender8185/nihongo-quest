# 言靈、山上的古道具屋、擺設、主角 — 設計

日期：2026-11-07　狀態：使用者授權「一路照建議直接完成後上 test」（2026-11-07），不再逐段確認　分支：`test`（測試站），不上 main

## 1. 需求（使用者原話整理）

1. 加貨幣：每做完一輪 20 題給 1，做完全日練習給 10。
2. 戶外遠處的山上有販售處，可以買商品；先把書房現在的掛鐘拔掉，改成在那裡賣。
3. 商店開在左側的山，山矮一點；販售處和貨幣換成更有「知識能量」感的東西。
4. 商店上架 40 件不同的商品；大部分商品可以讓使用者自由擺放，怎麼擺由我設計。
5. 加一個主角：能和主要的功能性物件互動，能讓使用者把主角移動到各個地方；商品也可以是主角身上的東西。
6. （補充）主角也要可以離開房子、在房子外移動；古道具屋加一個 NPC 角色。

## 2. 已決定的事

- 一輪 = 今日練習的一組（含當天做完後的「多學」組），要做到最後；中途按「結束」不算。當天最後一組不滿 20 題也算一組。單元／主題／錯題本／漢字／假名練習不給。
- 全日 = 當天清單（書房筆記本的百分比）第一次到 100% 時給 10，一天一次，兩台裝置都做完也只給一次。
- 貨幣叫「言靈」（圖示：一顆發光的「あ」），寫「言靈 12」「+1 言靈」，不用「枚」。
- 販售處是「古道具屋」：院子左邊一座矮山的山頂，木造老店、瓦片屋頂、寫「古」的暖簾、紙燈籠；老闆不收錢，只收言靈。
- 掛鐘賣 1 言靈；買回來掛回原位（書櫃上方左牆）。
- 現有使用者從 0 開始；信箱多一封信說明。
- 言靈只靠讀書得到，跟付費無關。

## 3. 言靈

### 3.1 存法（跨裝置不少算、不重複算）

```
state.koto  = { sets: { <deviceId>: n }, days: ['YYYY-MM-DD', …], gift: n }
state.owned = { <itemId>: { paid: n, on: 'YYYY-MM-DD' } }
```

- `koto.sets[裝置]`：這台裝置做完幾組（只有它自己會加，所以合併取大的值就是準的）。裝置 ID 用 `Sync.meta.deviceId`，拿不到時用 `'local'`。
- `koto.days`：拿過「全日 +10」的日子（聯集，同一天不會給兩次）。
- `koto.gift`：只有測試站的「+100 言靈」按鈕會寫（取大的值）。正式站沒有這個按鈕。
- `owned`：買過的東西和當時付了多少（聯集；同一件在兩台都買只算一次）。
- 餘額 `kotoBalance() = Σ sets + 10 × days.length + gift − Σ owned.paid`。兩台離線各買不同東西時可能出現負數，照實顯示。
- `sync-core.mergeStates`：sets 每個 key 取大、days 聯集、gift 取大、owned 依 key 聯集。其他新欄位（`placed`、`wear`）照現有規則取較晚存的那份。
- `normalizeState` 補齊形狀；不認得的商品 id 一律保留（1.0.34 的規矩：不要因為這版不認得就丟掉紀錄）。

### 3.2 什麼時候給

`renderSummary`（階段測驗除外）第一次畫出時算一次，記在 `SESSION.koto`，之後重畫不再給：

- `+1`：`SESSION.mode === 'daily'`、`!SESSION.quit`、有作答。
- `+10`：`dayProgress()` 的 `left === 0 && total > 0`、今天有作答、`koto.days` 還沒有今天。用任何模式把清單做完都算（跟筆記本百分比一致）。
- `exitPractice` 中途結束時設 `SESSION.quit = true`。

### 3.3 顯示

- 結算卡：數字格下面一列「言靈 +1 做完一組｜+10 今日完成｜共 N」，沒賺到就不出現；數字跟著 count-up。
- 書房右上角：`[言靈 N] [擺設] [設定]`；點言靈到古道具屋。
- 古道具屋頁上方櫃台的錢包。

## 5. 擺設

### 5.1 資料

```
state.placed = { <itemId>: { w: 'F', x, y, r } | { w: 'L', u, v } | { w: 'R', u, v } }
```

- `F` 地上：`x, y` 是佔地中心（房間座標），`r` 0／1（轉 90°，佔地長寬對調；圓的東西左右翻）。
- `L` 左牆（x=0）、`R` 右牆（y=0）：`u` 沿牆位置、`v` 高度，都是中心。
- 沒有出現在 `placed` 的已買擺設 = 在收納箱。整份取較晚存的那份（是擺法，不是進度）。

### 5.2 規則

- 地上的東西不能疊在家具（書櫃、書桌、椅子、櫃子、盆栽、床頭櫃、床、雨傘）、門開的範圍、主角跟功能物件互動要站的位置、其他地上的東西上；地墊可以壓在家具下面，但地墊之間不能疊。
- 牆上的東西只能掛在腰板以上、燈串以下，不能疊到窗戶和窗簾、門、軟木板、日曆、版畫、掛勾、床頭的畫、高家具的輪廓、其他牆上的東西。
- 吸附 0.25 單位。不合法的位置顯示紅色，放開時回到上一個合法位置。

### 5.3 擺設模式

- 書房右上角「擺設」進入；畫面上方「完成」離開。
- 下方收納箱一排縮圖（取代停點列）；點一下放到畫面中間附近的空位並選取。
- 點已擺的東西選取；拖曳移動（拖的時候畫在單獨一層，放開才重畫房間）；選取後在旁邊出現「轉向」「收起」。
- 選取時點空地：東西直接移過去（可以先左右滑到另一個停點再點）。
- 空白處左右滑動照樣換停點。主角在擺設模式時先隱藏。

### 5.4 畫法（深度排序）

房間大圖分三層：牆和牆上的東西 → 地板、地墊 → 站在地上的東西（家具與擺設）依前後排序（兩個佔地在畫面上重疊時：`a.x1 ≤ b.x0` 或 `a.y1 ≤ b.y0` 的在後面；佔地互相重疊就比底部高度，再比中心 x+y）。掛鐘變成一般牆上商品（`.clock-hands` 跟著它的位置和牆面）。沒買掛鐘時，原位置留一根釘子。

## 6. 主角

- Q 版人物，短髮、靛藍色連帽衫，約 4.3 單位高；正面和背面兩種角度（左右翻），姿勢：站、走（腿和手擺動）、坐、伸手。
- 畫在大圖上方的一層 HTML（自己一層，移動不重畫大圖）。被家具擋住的部分：大圖上方再一層「前景」SVG，只放此刻應該在主角前面、且畫面上和主角重疊的家具／擺設的複本；主角換格子時才更新。
- 夜裡的顏色用和房間一樣的打光（停下來時依位置重算）。
- 移動：地板 0.5 單位一格，A* 繞過家具和擺設；點空地就走過去（擺設模式除外）。走路速度約每秒 6 單位，路太長就加快，最多約 1 秒。動作減少時直接到位。
- 互動：點功能物件 → 主角走到它的位置、轉向、做動作 → 原本的轉場 → 頁面。

| 物件 | 站的位置（x, y） | 動作 |
|---|---|---|
| 筆記本（今日練習） | 椅子（3.4, 3.15） | 坐下 |
| 耳機（聽一輪） | 書桌右前（4.6, 2.9） | 伸手 |
| 書櫃／卡片盒（課程／單字） | 書桌左前（1.9, 2.9） | 伸手 |
| 抽屜（錯題本） | 櫃子前（8.45, 2.45） | 蹲低伸手 |
| 軟木板（學習分析） | 櫃子前（8.45, 2.45） | 抬頭看 |
| 日曆（模擬考） | （10.65, 1.3） | 伸手 |
| 門（出門） | 門前（1.25, 5.1） | 朝門走 |
| 留聲機（擺了的話） | 它前面 | 伸手 → 聽一輪 |

- 同一個東西再點一次：跳過走路直接進。
- 從頁面回到書房：主角在那個物件前（今日練習回來是坐著）。
- 位置只存在這台裝置（localStorage `nq_hero`），預設在書桌前。
- 點主角：開「衣櫃」視窗，依部位列出已買的穿戴品，點了穿上／脫下。穿戴存 `state.wear = { head, face, neck, back, body }`（取較晚存的那份）。

### 6.1 院子裡的主角

- 主角在哪個場景就跟著在哪：從書房的門走出去，院子裡的主角從房子門口走出來；在院子點房子，主角走到門口進屋，書房裡的主角出現在門內。用上方「‹ 書房」或側邊欄回書房時，主角就在書房（上次在書房的位置）。
- 院子是正面看的平面圖，主角用同一套畫法，依遠近縮放：房子門口約 30px 高，畫面最下面約 80px。可以走的範圍是房子底線（地面）到畫面下緣。
- 點地面走過去；點信箱：走到信箱旁再打開；點房子：走到門口再進屋；點古道具屋：走到左邊山路口，沿山路變小淡出，再開古道具屋頁。
- 主角在信箱後面時信箱擋住主角（比底部的 y）。晚上主角跟著院子變暗（filter 依 `--day`）。
- 院子的位置也只存在這台裝置（`nq_hero` 裡分 room／yard）。

### 6.2 古道具屋的老闆（NPC）

- 一隻貓頭鷹老闆「福爺」（フクロウ＝不苦労，又是智慧的象徵，收言靈很合理）：圓眼鏡、小圍裙。

  - 進門：「いらっしゃい（歡迎光臨）」等幾句輪流

  - 不夠時按買：「言靈がまだ足りないね（言靈還不夠喔）」
  - 晚上：「こんばんは（晚安）」
- 院子山上的店門口也有一隻很小的福爺。點頁面上的福爺會換下一句。

## 11. 追加（同一天）：書房原本的東西也能搬

使用者：「放在目前室內的滿多物品也不需要寫死的，讓大部分東西都可以收納和自由移動」，再補充「如果有功能性的東西只是不能收但能搬呢」。

- **原本就有的裝飾（可搬、可收）**：床、床頭櫃（檯燈的光跟著它）、觀葉植物、雨傘、圓地毯、床邊地毯、腳踏墊、富士山版畫、平假名表、夜空畫、掛勾架。商品目錄裡標 `starter`，不在古道具屋賣。
- **功能物件（可搬、不能收）**：書櫃（課程、單字）、書桌連椅子（今日練習、聽一輪、主角坐的位置）、抽屜櫃（錯題本）、軟木板（學習分析）、日曆（模擬考）。標 `fixed`：不進收納箱，擺設工具列只顯示「只能搬，不能收」，不能轉向。
- **門、窗**是房子的結構，不動。
- 第一次載入時（`roomV` < 2）把上面這些擺在原本的位置；功能物件永遠補回 `placed`。新帳號和重設進度也會經過 `normalizeState`。
- 功能物件用同一個 mover 移動：地上整組平移，牆上沿牆平移或用兩面牆之間的斜切換到另一面牆。圖、點按範圍、轉場層、主角站位（牆上的是牆前第一個空格）、燈光、光暈都跟著走；名牌所屬的停點依位置重算。
- 靠牆的高家具會擋住那面牆（牆上的東西不能掛在它後面），反過來也一樣。牆面保留區只剩門和窗。
- 買來的落地燈、行燈晚上會照亮附近。

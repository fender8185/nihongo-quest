# 觀光郵輪 — 設計

日期：2026-11-12　狀態：使用者交給我照建議做（「接下來的故事和內容就靠你安排了」「其他都照你的建議來嘍」），只上測試站
基準：test = main 1.14.2（60f400b）

## 1. 目標

使用者想看看「觀光郵輪＋我們當導遊」這個循環好不好玩，說不定變成 App 的主打。這一輪只做體驗：

- 一艘看起來巨大又豪華的郵輪，遠遠停在みなと漁港左邊的海平線上；點它，它飛快地開進港、靠岸、放下舷梯。
- 八個遊客一個一個下船（各說一句自我介紹），擠在一起七嘴八舌。
- 真導遊高橋負責講，主角當助手：數人頭、指路、回答遊客的問題（選回答）。
- 十幾次的介紹，以幽默為主；難度：N5 第 3–4 週結束（m2）。
- 先不做薪水（使用者：「重點是體驗看看這個循環」）。

## 2. 什麼時候來

- 課程過了導覽的單元（`TOWN.CRUISE.u`，這一輪是 m2）。
- 正式站：船期是週二、週六 9–17 點；第一次不管星期幾。導覽開始後就留到結束。
- 測試站：每天、任何時間；町の手帳的測試工具「郵輪：現在叫來（不看日子、時間、進度）」「郵輪：今天的從頭開始」。
- 只記在這台裝置（`localStorage` 的 `nq_cruise`：day、step 下一站、place 遊客在哪、done、ever），不同步——之後做薪水時再進 `state`。
- 船在海上時，進院子、海邊、漁港會提示一次「漁港外的海上，好像來了一艘好大的郵輪！」。

## 4. 畫面

- 郵輪畫在漁港的地面 SVG 裡（燈塔後面、漁船和漁會前面），船尾在燈塔右邊、船頭朝右；遠方是同一張圖縮成 0.085 倍。
  五層甲板（陽台玻璃、救生艇）、紅色煙囪、滿船旗、遮陽傘和滑水道；晚上窗戶亮燈。舷梯從船身的門放到碼頭。
- 遊客和高橋用居民的紙娃娃零件畫（`HERO.svg`），高橋拿一面寫著「みなと」的橘色導覽旗。
- 每一站：主角和高橋走到定點，遊客擠成兩排（新婚夫妻永遠站一起，每站換順序），鏡頭移到能看到所有人的地方（手機只看得到約 250 px 寬）。
- 有人說話時他會跳一下；「みんな」一起說時所有人一起跳。沒在對話時每一秒多有人冒一句（最多三個泡泡），偶爾有人擠來擠去。
- 畫面下方的導覽條：「3/13 漁會 下一站 ▶」；下一站在別的地方時是「一起去海邊 ▶」「回漁港 ▶」；最後一站是「送客人上船 ▶」。點高橋也等於下一站。
- 主角在漁港和海邊之間走，遊客會跟著；去別的地方（大馬路、院子）時遊客留在原地，回來還在。

## 5. 資料

`events.js` 的 `TOWN.CRUISE`：`u`、`ship`、`PEOPLE`（八個遊客的樣子）、`OFF`（下船時說的話）、`SAY`（閒聊）、`TOUR`（每站：
`at`、`hero`、`crowd`、`lost`、`need`、`lines`、`after`）。`scripts/check-events.js` 一起檢查（漢字讀音、等級、選回答的文法單元、人都存在、
從漁港開始到漁港結束）。聲音：八個遊客各有 Chirp 3 HD 的聲音（`CAST_VOICE`），台詞進了產生器的清單，要按一次「生成」。

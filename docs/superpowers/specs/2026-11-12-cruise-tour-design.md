日期：2026-11-12　狀態：使用者交給我照建議做；這一版先做第 1、2 趟，只上測試站
基準：test 1.14.2-test.1（c0595d8，第一版：一趟 13 站、m2 程度）

## 0. 使用者這次說的（2026-11-12）

- 也要帶遊客**進餐廳和居酒屋**；整個進程可以更長，一趟超過 20 題沒問題。
- 這些遊客**綁死成固定團員**，以後只增不減，**每一趟多一個新角色**。

- 先不做薪水（上一輪說的）。

## 1. 一趟一趟的規則

### 1.1 航次（trip）

- 每個單元一趟：t1＝m1、t2＝m2 … t33＝m33。每一趟的日文只用到那個單元為止學過的文法（選回答的 `pt` 檢查），單字以那一級為主（檢查腳本照舊）。
- 一趟至少 **20 個選回答**，多半練那個單元的文法，少數複習。
- 依序來：上一趟走完才會來下一趟，而且**不同一天**（測試站不限）。
- 第 t 趟什麼時候開：
  1. 課程到了：那個單元已經學過一半的文法，或已經學到更後面的單元；
  2. 上一趟做完（t1：改成「高橋的事件做完」，見 §3）。
- **不看時間**：晚上來就是夜間導覽（郵輪點燈）。導覽路線上的店在遊客到的時候都開著（店主在）。
- 舊學習者（已經在 m5 的人）：從 t1 開始，一天一趟補上來。

### 1.2 一趟的流程

1. 郵輪遠遠停在みなと漁港左邊的海平線上（進院子、海邊、漁港各提示一次）。
2. 點郵輪 → **確認視窗**：「豪華郵輪靠港了！這趟導覽約 N 站、20 多分鐘，可以中途離開，下次從同一站繼續。現在開始嗎？」〔開始導覽〕〔等一下〕。
3. 郵輪開進港、放舷梯；團員一個一個下船；新團員最後下船、自我介紹。
4. 一站一站走。下一站在相鄰的地方：大家一起走過去（現在的做法）；不相鄰的地方（搭公車去白鷺城、從城回小鎮）：畫面淡出、一句字幕（「🚌 大家一起搭公車去白鷺城」），到了之後大家從入口走進來。
5. 最後一站在漁港：大家上船、郵輪開走。
- **中途離開**：去別的地方或關掉 App 都可以；郵輪一直停在港口，遊客在原地等，導覽條寫「遊客在〇〇等你」。進度跟著雲端同步，換裝置也接得上。

### 1.3 固定團員

- t1 的八個人是創團團員（金田、梅子、ゆうた、リナ、吉本、健、愛、道山）；每一趟加一個人，**只增不減**。
- 台詞只能由「這一趟已經在團裡的人」說（檢查腳本檢查）。
- 每個團員有：樣子、聲音、下船時說的話與閒聊（**依單元**增加，學到哪說到哪，跟居民的閒聊一樣）。
- **人數上限（2026-11-13 使用者同意）**：名冊只增不減，但上岸最多 16 人（t9 起才會超過）。超過時，每趟上岸的是「這趟的新團員＋這趟台詞用到的人＋輪流的幾位」，其他人在甲板上揮手。資料預留 `party`（這一趟上岸的人；不寫＝全部），寫到 t9 時實作。

### 1.4 吃飯的店

- 每一趟（或大部分）有一站在店裡吃飯；**相連的兩趟不同家**。
- 現在能進去的：まんぷく食堂（t1）、居酒屋とり吉（t2，鉄平為了旅行團白天特別開店）。
- 之後要新增的店（各要一個室內場景）：喫茶しずく、駅前のラーメン屋、城下町のそば屋、みなとの寿司屋、郵輪上的餐廳；夏天的海之家、緣日的屋台也可以當一站。

## 3.5 聲音與站位（2026-11-13，第 3 版）

- **配樂**：導覽有自己的曲子「みなと案内」（`music/minato-1.m4a`，`scripts/music-synth.js` 的 `minato`：F 大調、輕搖擺，笛子主旋律、撥弦、走路貝斯、刷子鼓）。遊客在哪裡就在哪裡放（`CRUISE.tune`），居酒屋照放自己的「赤ちょうちん」；說話時照常壓低。
- **音效**：郵輪遠方出發和靠岸、離港時的汽笛（`sounds/shiphorn-1.m4a`）；上下舷梯的木板腳步聲；送完客人的完成音。台詞可以帶音效：`[人, 日文, 中文, { snd }]`（例：冷笑話後的冷風 `brr`、閃光的 `heart`、拍照 `shutter`、乾杯 `cheers`）。
- **みんな一起說**：不再用一個聲音唸。五個團員（金田、梅子、リナ、吉本、健）的聲音錯開幾十毫秒疊在一起（`speakChorus`），像一句快速的吐槽；生成器為每一句幫這五人各做一段。冷笑話的吐槽寫成「さむっ！」配冷風聲。
- **笑聲、叫聲不用合成語音**：みんな 的「あはは！」播觀眾笑聲（`laugh`，只留笑得最大聲那一段）；有情緒的叫聲在台詞上標 `{ cry }`，播音效不唸（吉本被螃蟹夾：`ouch` 加 `pinch`）。其他有「〜」拉長音、同一個詞重複喊的台詞改寫成平常的句子。
- **站位**：遊客站在畫面前面（Y 小），店面、店主、介紹的東西在後面露出來；高橋站在主角離遊客較遠的那一側，或照這站的 `guide`；店主走到自己店前（`cast`）；大馬路上站人行道，人行道窄時三排（`rows: 3`）；公車站這一站公車真的開進來停（`bus`：停的 X），道山上車＝走到公車後面，台詞可帶 `{ move: [人, [X, Y]] }`；手機鏡頭可指定（`cam`）。
- **郵輪本身**：甲板上的陽傘和滑水道站在各層甲板頂上；舷梯從船門往右下到漁協前，不再穿過漁船。

## 3.6 導遊的報酬：言靈、円、評級、導遊證（2026-11-13，使用者定的）

- **言靈**：每個選回答一次就答對 2、錯一次才對 1、最後才選 0（同一題只算第一次答，中途離開再回來不重算：`on.score` 記每題錯幾次）。一趟結束時一次給，記在 `state.koto.found['cruise-tN']`。
- **円（第二種貨幣，100 円硬幣）**：導遊費照課程程度固定——N5 的趟 5,000 円、N4 7,000、N3 起 10,000——再照評級每高一級多 200 円（E 是基本，S 多 1,000）。錢包上限 9999 萬円。記在 `state.cruise.res[趟] = { first, asks, koto, yen, grade, day }`，錢包＝所有導遊費相加（之後扣掉花掉的）。一天最多一趟，所以 N1 新手也不會一下子賺太多。
- **評級**：一次就答對的比例：S ≥95%、A ≥85%、B ≥70%、C ≥50%、D ≥30%、E 以下。
- **導遊證**（帶過的趟數）：1 趟起「見習いガイド」、3「ガイド」、8「ベテランガイド」、15「主任ガイド」（m15 高橋交旗）。
- **結算畫面**：郵輪開走後跳出，數字一個一個往上跳（叮叮聲），最後評級印章「碰」地蓋在卡片角上（震一下）＋完成音；第一次拿到円時，收下後高橋說明円是什麼。
- **上方的言靈數字**：點一下切換看錢包有多少円（不再直接去古道具屋，古道具屋走上山）；顯示哪個記在這台裝置。
- **花円（第二輪，2026-11-13 做好）**：鎮上有菜單的東西（`PLACE_USE` 的 `buy` → `events.js` 的 `TOWN.MENU`）點了打開菜單：日文名稱、價格上方標讀音（例：180円 ひゃくはちじゅうえん），點「中文」才看中文。買了扣円（`state.purse.spent`，每台裝置各自累加，同步時各取大的），主角用日文點「〇〇を ください。」、店主用自己的口氣說價錢（收錢聲），販賣機和籤筒直接投錢。之後照那樣東西本來的動作：販賣機掉罐子、牛奶「ぷはー！」、澡堂進去泡、抽籤；食堂和居酒屋坐到空位「いただきます！」，過一會兒「ごちそうさまでした！」。每樣第一次買的蓋章進「美食手帳」（町の手帳的新分頁，有円之後才出現）。還沒有円時菜單照樣看得到，但不能買，告訴你帶郵輪導覽賺導遊費。移動不收錢。
  - **（使用者再加的）**：菜單上的東西要先學會它的單字（例：カレー、ラーメン、パン、牛乳；或課程已經超過那個字的程度）才會出現，還沒學到的顯示模糊的「？？？」和「學會「〇〇」這個字，就能點」。一天最多吃兩樣、喝一杯，超過時主角說「まだ おなかが いっぱいです。」（飲料「もう のめません。」），店主回「また あした どうぞ！」，不扣錢。每樣東西都有圖（課程的字用 `pics.js` 的 `PICS`，課程外的からあげ、メロンパン、焼き鳥、えだまめ、クリームソーダ、缶コーヒー、瓶裝牛奶、おみくじ等放在 `PICS_TOWN`）。買了之後有自己的進食畫面：主角的臉部特寫（眼睛冒星星、愛心往上飄、嚼東西時臉會動），旁邊是食物的圖，一口一口被咬掉（もぐもぐ、有齒痕的咬口、碎屑；有盤子、碗的料理，咬掉的地方露出乾淨的空盤），飲料是舉起來喝（ごくごく）；吃完主角對這樣東西大大稱讚三句（日文，一句一點、會唸出來，中文點了才看），最後「ごちそうさまでした！」，第一次吃的再蓋美食手帳的章。
  - **（使用者再加的，2026-11-13）**：點東西要跟店主說話：點トメ、健太、渚、鉄平、松，他們先打招呼，再選「ちゅうもんする」（澡堂是「おふろに はいる」）或「おしゃべりする」（按鈕用日文，用假名才對得齊）（有等著的事件時先做事件）；牆上的菜單、黑板、麵包架也照樣能點。進食畫面分三段：吃之前主角眼冒星星、張嘴流口水（じゅるり），先說兩句這樣東西看起來多好吃（look），按「いただきます！」才開始吃；吃的時候眼睛笑成 ^ ^、嘴巴嚼著（ω）；吃完愛心眼大笑、愛心飄、「好吃」的音效，再接著稱讚三句（say），最後「ごちそうさまでした！」，第一次吃的蓋章時還有閃亮聲。
  - 地點與價格（照各店牆上的菜單、黑板）：販賣機（大馬路、車站）110–150；森のパン 160–280；喫茶しずく 400–700；まんぷく食堂 100–800；居酒屋とり吉 120–480；月の湯 泡湯 480、牛奶 150；稲荷神社 おみくじ 100。

## 4. 資料與程式

- `events.js` 的 `TOWN.CRUISE`：
  - `ship`；`PEOPLE`：每人 `from`（加入的那一趟）、樣子、`party` 預留；
  - `OFF`、`SAY`：`[單元, 日文, 中文]`，學到哪說到哪；
  - `TRIPS`：`[{ id, u, title, needs（先做完的事件）, join（新團員）, stops }]`；
  - 一站：`at`、`title`、`hero`、`crowd`（室內：`room: true` 時是地板的 [u, v]，`seat: true` 時團員坐進店裡的座位）、`lost`、`need`、`cast`（這站要出場的居民和位置：不在就請他出來）、`lines`、`after`、`go`（不相鄰時怎麼去：`'bus'`、`'walk'`）。
- 進度：`state.cruise = { done: { t1: 日期 }, on: { trip, step, place } | null }`，同步時 `done` 取聯集、`on` 用比較新的那份（它那一趟在任一邊做完了就清掉）。提示過的日子只記在這台裝置（`nq_cruise_told`）。第一版的 `nq_cruise` 不再用。
- `scripts/check-events.js`：每一趟的單元依序遞增、台詞的人在那一趟已經入團（或是居民、主角、みんな）、選回答至少 20 個、第一站和最後一站在漁港、最後一站送客（`bye`）、`cast`/`need`/`needs` 都存在。
- 測試站：町の手帳「郵輪：現在叫來（下一趟）」「郵輪：從第 1 趟重來」「郵輪：跳到第 N 趟」。

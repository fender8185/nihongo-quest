# Cat_01

暫定的吉祥物（2026-11-05 採用）。原本是一張霓虹線條的坐姿貓 PNG，描成向量、拆成部件後，以這裡的檔案為準，原 PNG 不再使用。

打開 `gallery.html` 就能看全部動作：每個按鈕播一次，可以開「無聊輪播」或「依序播放全部」。網址加上 `#play=happy.10` 只顯示舞台，並重複播那一個動作。

## 檔案

| 檔案 | 內容 |
|---|---|
| `geometry.json` | 主檔：從原圖描下來的線（頭、身體、左前腳、中間線、右前腳、尾巴），1024×1024 座標 |
| `draw.py` | Cat_01 的姿勢；共用的幾何、光暈、表情、特效在 `../neon_cat/neon.py` |
| `build.py` | 跑 `python3 -I design/cat_01/build.py`，產生下面三個檔案 |
| `cat_01-data.js` | 播放器用的資料（產生出來的，不要手改） |
| `cat_01.svg`、`cat_01-ball.svg` | 單張的坐姿和球，不需要播放器也能用 |
| `actions.js` | 80 組動作的時間軸 |
| `gallery.html` | 動作庫展示頁 |

播放器、動作寫法、展示頁的介面和錄影工具都放在 `../neon_cat/`，跟 Cat_02 共用（見那裡的 README）。

## 怎麼組成的

- **一顆頭通用所有姿勢**：坐、趴、側面、站、翻肚都用同一顆正面的頭，所以表情只要一套。側面走路時臉還是朝向你。
- **姿勢**（`draw.POSES`）：`sit` 坐（原圖描的，不動它）、`loaf` 趴、`side` 側面（圓身體、短胖腿）、`back` 背面、`belly` 翻肚（兩側都有腳）、`stand` 站、`ball` 球。
- **可以替換的零件**：
  - 頭：`headFlat` 飛機耳、`headFlatHalf` 半垂、`headTwL`/`headTwR` 耳朵抖動、`headPerk` 耳朵豎起。用 `twitch`、`earsTo` 切換，每個有臉的姿勢都有。
  - 手：`pawR_up` 舉右手、`pawR_lick` 手舉到嘴邊、`pawL_up` 舉左手、`armL_palm`/`armR_palm`（站姿舉手時露出肉球）。
  - 球：`ballTwL`/`ballTwR` 耳朵抖動。
- **肉球**：掌心朝外的腳都畫了粉紅色的肉球（一個大肉墊加三顆小的），會跟著那隻腳一起動。
- **圖層**：-1 是遠側的腳（較暗，在身體後面），0 是身體，1 是在前面的手腳（會用暗色光暈蓋住後面的線），2 是肉球。
- **表情的欄位**：`eyes`、`mouth`、`tongue`、`brows`、`cheeks`，各自換，可以任意組合。例如眼睛 `heart` 配嘴 `w` 配臉頰 `blush`。
- **特效**：愛心、星星、閃光、音符、Z、驚嘆號、問號、生氣符號、汗滴、蒸氣、烏雲、雨、燈泡、點點點、彩帶、速度線、書、魚、毛線、假名「あ」、勾勾、放大鏡等。
- **光暈**：每條線都是 8 層由暗到亮的筆畫，最上面再疊一條亮芯，亮度照原圖量的。沒有用 SVG filter，舊手機也能正常顯示。

## 動作的寫法（actions.js）

每組動作是一段時間軸（毫秒），寫在 `act(id, 名稱, 長度, b => ...)` 裡：

```js
act('wink', '眨眼', 2000, (b) => {
  b.face(200, {eyes: 'wink', mouth: 'smile'}).face(1700, {eyes: 'normal', mouth: 'w'});
  b.hold('head', 150, 1800, {r: 5});
  b.fx(300, 'sparkle', {x: 620, y: 360, s: .4, anim: 'pop', dur: 800});
});
```

- 部件：`move`（在舞台上移動）、`flip`（左右翻面）、`cat`（整隻壓扁拉長，支點在腳底）、`head`、`eyes`、`tail`、`ball`、`pawR_up`、`armL`/`armR`、`legFN`/`legFF`/`legBN`/`legBF`、`glow`（地上的光）。
- 常用的組合：`blink` 眨眼、`wag` 搖尾巴、`hop` 跳、`nod` 點頭、`shake` 抖、`hold` 動過去停住再回來、`swap` 在快速壓扁的瞬間換姿勢、`turnTo` 轉身（可以順便換面向）、`tuck`/`untuck` 坐姿和球互換、`roll` 滾、`walk` 走或跑。
- 規則：每組都從休息狀態開始、回到休息狀態結束，所以任兩組可以接著播。換姿勢一律在動作最快的那一格換，不用淡入淡出，否則會出現兩隻貓重疊的鬼影。
- 滾動時，轉的角度跟走的距離綁在一起（一圈 = 2π × 183 ≈ 1150），不會打滑；停下來要剛好整圈，耳朵才會朝上。

## 已知限制

- 正面坐姿是原圖描的，兩隻前腳共用中間那條線；舉左手時左下會少一段線。需要兩手一起動的動作請用 `stand`。
- 歪頭大約 4 到 10 度就會讓脖子的接縫變明顯。
- 只有前面那層的手腳會遮住後面的線；身體和頭之間沒有遮擋（霓虹燈的畫法）。
- 趴、側面、背面、翻肚、站、球是照原圖的風格新畫的，不是描的。

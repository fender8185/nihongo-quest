# Cat_02

站著的雙腳貓（2026-11-06）。從三張圖描出來：站著、站著揮手、坐著伸腿揮手。頭跟 Cat_01 是同一個家族，表情、耳朵動作、特效都共用（見 `../neon_cat/README.md`）。原圖沒有臉，這裡跟 Cat_01 一樣加上眼睛和 ω 嘴。

打開 `gallery.html` 就能看全部 100 組動作。網址加上 `#play=dance.robot` 只顯示舞台，並重複播那一組。

## 檔案

| 檔案 | 內容 |

| `geometry.json` | 主檔：從三張圖描下來的線，已縮放到共用的頭部座標（頭寬 208–742，腳底 y 1012） |
| `draw.py` | 姿勢：站、坐（描的）、背面（站姿鏡像加尾巴），加上跟 Cat_01 共用的趴、翻肚、球 |

## 部件

- **手**：放下（`sideR`、`sideL` + `hipL`）和舉起（`sideR_up`、`sideL_up`）是兩張不同的圖，在手快速擺動的瞬間切換。舉起的左手是右手鏡像過來的。
- **舉起的手會繞肩膀轉**（部件 `armR` / `armL`）：右手 +31 度是平舉指向右邊，-40 度舉高，-62 度敬禮，-85 度把手放到嘴邊。左手的角度自動鏡像。
- **腳**：`legs` 站立、`legsL`/`legsR` 抬起一隻腳（走路、踏步、跺腳就是兩張輪流換）、`legsSit` 坐著伸腿。
- **走路**：Cat_02 是面向你搖搖擺擺地走（左右腳輪流抬、身體往另一邊靠、眼睛看著前進的方向），所以沒有側面姿勢。
- **頭、表情、尾巴**：跟 Cat_01 一樣。頭的轉軸在脖子 (476, 594)，尾巴根在 (638, 840)。

## 已知限制

- 坐著時只能舉右手（你的坐姿圖是舉右手）。
- 手轉得角度很大時，手臂根部和身體之間會有一點縫。
- 背面、以及共用的趴、翻肚、球是照風格畫的，不是描的。
